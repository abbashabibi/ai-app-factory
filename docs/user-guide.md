# راهنمای استفاده — AI App Factory

## شروع سریع

### 1. ورود
با حساب کاربری خود وارد پلتفرم شوید.

### 2. فعال‌سازی لایسنس
در اولین ورود، License Key خریداری‌شده را وارد کنید. سیستم اعتبار لایسنس را بررسی و آن را به حساب شما متصل می‌کند.

### 3. ساخت پروژه YouTube
از داشبورد، «پروژه جدید» را انتخاب کنید و موضوع، زبان، سبک محتوا و نوع ویدئو را مشخص کنید.

### 4. اجرای AI Factory
عامل هوش مصنوعی مراحل تحقیق، ایده‌پردازی، اسکریپت، تولید دارایی‌ها، مونتاژ، زیرنویس، عنوان و توضیحات را طبق تنظیمات پروژه مدیریت می‌کند.

### 5. کنترل کیفیت
قبل از انتشار، خروجی باید از کنترل‌های کیفیت عبور کند. در صورت وجود خطا، پروژه متوقف می‌شود و علت در داشبورد نمایش داده می‌شود.

### 6. انتشار در YouTube
پس از اتصال امن کانال و تأیید مجوزهای لازم، انتشار طبق حالت انتخاب‌شده انجام می‌شود. پیشنهاد پیش‌فرض برای پروژه‌های جدید، انتشار خصوصی و بررسی دستی است.

## لایسنس مادام‌العمر

لایسنس Lifetime تاریخ انقضا ندارد. «مادام‌العمر» به معنی استفاده بدون انقضای خود محصول است و هزینه یا سهمیه سرویس‌های شخص ثالث مانند مدل‌های AI، YouTube API، صدا، تصویر و زیرساخت می‌تواند طبق شرایط محصول جداگانه باشد.

## نکات مهم

- کلید لایسنس خود را در اختیار دیگران قرار ندهید.
- API Key و اطلاعات ورود YouTube را داخل پروژه یا فایل‌های عمومی قرار ندهید.
- برای هر کانال فقط از حساب و مجوز قانونی خود استفاده کنید.
- اگر پروژه خطا داد، ابتدا پیام خطا و مرحله متوقف‌شده را بررسی کنید.

## مسیر پیشنهادی برای کاربر جدید

`ورود → فعال‌سازی لایسنس → اتصال YouTube → ساخت پروژه → تولید محتوا → کنترل کیفیت → بررسی → انتشار`

راهنما باید داخل محصول نیز به‌صورت Onboarding مرحله‌ای و Help Contextual نمایش داده شود تا کاربر بدون آموزش خارجی بتواند کار را شروع کند.
