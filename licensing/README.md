# Lifetime Licensing

## مدل فروش

محصول از **لایسنس مادام‌العمر (Lifetime License)** پشتیبانی می‌کند. کاربر با یک خرید، حق استفاده از نسخه‌ای از محصول را بدون تاریخ انقضا دریافت می‌کند.

### نکته مهم
«مادام‌العمر» به معنی دسترسی نامحدود و بدون هزینه به سرویس‌های شخص ثالث نیست. هزینه و محدودیت سرویس‌هایی مانند YouTube API، مدل‌های AI، تولید صدا/تصویر و زیرساخت ابری می‌تواند جداگانه و بر اساس پلن/مصرف مدیریت شود.

## چرخه لایسنس

`PURCHASED → ISSUED → ACTIVATED → ACTIVE → SUSPENDED/REVOKED`

- **Issued:** لایسنس ساخته شده ولی هنوز فعال نشده.
- **Activated:** کاربر لایسنس را به حساب خود متصل کرده است.
- **Active:** لایسنس معتبر و قابل استفاده است.
- **Suspended:** موقتاً غیرفعال شده، مثلاً در صورت تخلف یا مشکل پرداخت سرویس‌های جانبی.
- **Revoked:** برای همیشه باطل شده؛ مثلاً در صورت سوءاستفاده جدی یا درخواست انتقال مالکیت.

## مشخصات پیشنهادی لایسنس

هر لایسنس شامل موارد زیر است:

- `license_id`
- `license_key` (فقط نسخه رمزنگاری‌شده در سرور نگهداری شود)
- `plan = lifetime`
- `expires_at = null`
- `account_id`
- `max_devices`
- `max_channels`
- entitlementهای فعال
- تاریخ صدور و فعال‌سازی
- وضعیت لایسنس
- لاگ فعال‌سازی/انتقال/لغو

## امنیت

- کلید خام لایسنس در دیتابیس ذخیره نشود؛ hash امن ذخیره شود.
- اعتبارسنجی اصلی سمت سرور انجام شود.
- محدودیت تعداد دستگاه و کانال قابل تنظیم باشد.
- امکان Deactivate و انتقال کنترل‌شده وجود داشته باشد.
- Rate limit برای validation و activation اعمال شود.
- اطلاعات حساس و API Keyها هرگز داخل اپ یا GitHub قرار نگیرند.

## قابلیت‌های پنل مدیریت

مدیر سیستم باید بتواند:

1. صدور لایسنس Lifetime
2. مشاهده وضعیت لایسنس
3. فعال/غیرفعال کردن
4. تعیین محدودیت دستگاه و کانال
5. انتقال مالکیت با ثبت Audit Log
6. لغو یا تعلیق در صورت سوءاستفاده
7. مشاهده تاریخچه فعال‌سازی
8. صدور مجدد یا جایگزینی کلید

## تجربه کاربر

در اولین ورود:

1. ثبت‌نام/ورود
2. ورود License Key
3. اعتبارسنجی خودکار
4. فعال‌سازی
5. نمایش «لایسنس مادام‌العمر فعال است»
6. نمایش راهنمای شروع سریع

این طراحی از ابتدا در معماری محصول لحاظ می‌شود تا بعداً نیاز به بازطراحی سیستم احراز مجوز نباشد.
